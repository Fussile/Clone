# Sidearm recording

Save the recording here as `SW_SidearmShot.wav`. Use mono, 16-bit PCM WAV, preferably 48 kHz.

Run `Tools/prepare_crossroads.py` in Unreal Editor, or run the normal Windows packaging script. Preparation imports the recording into `/Game/Audio/Weapons/SW_SidearmShot`. Replace the WAV and run preparation again to update the recording. A manually imported Sound Wave at the same Content Browser path also works when there is no source WAV in this directory.

Loot the sidearm and fire with the build menu closed to audition the shot.
