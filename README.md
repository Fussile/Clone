# Survival Co-op

UE5.8 C++ survival-crafting project inspired by the mechanics and atmosphere of 7 Days to Die A16–A18. Original implementation; working title pending. `Survival` is a provisional code identifier.

## Status

M0 project scaffold with a first-person C++ character. The test map, Steam sessions and survival systems are pending. Unreal compilation and multiplayer testing have not been performed.

## Getting started

Install Unreal Engine 5.8 and its supported C++ toolchain. Clone this branch, install Git LFS (`git lfs install`), generate project files from Survival.uproject, and build the SurvivalEditor Development target. Open Survival.uproject. For a movement smoke test, create a Basic level with a floor and Player Start and press Play. Controls are WASD, mouse and Space.

See [architecture](ARCHITECTURE.md), [decisions](DECISIONS.md), [asset manifest](ASSETS.md), and [M0 checklist](Docs/M0.md). Proposed choices remain provisional until confirmed by the developer.
